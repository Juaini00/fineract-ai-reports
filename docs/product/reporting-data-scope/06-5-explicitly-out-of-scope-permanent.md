# Reporting Data Scope: 5. Explicitly Out Of Scope

Source: `docs-old/reporting-data-scope.md`

## 5. Explicitly Out Of Scope

The following are out-of-scope of the current MVP boundary:

- Arbitrary SQL exploration — permanent; never built.
- Full Fineract schema search — permanent; never built.
- Loan account reporting — deferred (scheduled); see `knowledge/domains/loan.yaml`.
- Accounting/GL reporting — deferred (scheduled); see `knowledge/domains/accounting.yaml`.
- Tax reporting — deferred (scheduled); see `knowledge/domains/tax.yaml`.
- Custom datatable reporting — deferred (scheduled).
- Document/image/file reporting — permanent; never built.
- Identity document reporting — permanent; never built.
- Address-level reporting — permanent; never built.
- User audit reporting beyond fields needed for traceability — permanent; never built.
- Any write/update/delete action against Fineract — permanent; never built.
