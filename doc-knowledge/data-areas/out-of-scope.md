# Rejected areas

- Arbitrary SQL exploration
- Full Fineract schema search
- Document / image / file reporting
- Identity document reporting
- Address-level reporting
- User / audit reporting
- Fineract write actions

Hard-reject cases map to [../policies/unsupported-requests](../policies/unsupported-requests.md) and [../responses/unsupported](../responses/unsupported.md).
